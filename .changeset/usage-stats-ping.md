Loopress Full now sends an anonymous usage ping, at most twice a day, alongside its update check: a random site identifier, the Loopress, WordPress and PHP versions, the site language, timezone, and environment type. Never the site URL, an email, content, or the plugin list. On by default, switch it off under **Settings → Send anonymous usage statistics**. Loopress Light is unchanged and sends nothing.
