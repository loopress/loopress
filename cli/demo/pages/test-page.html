Test page

This is a test page pushed via lps page push. The file is the source of truth: editing it in wp-admin does nothing, the next push overwrites whatever was there.

What this page is for

It exists to exercise the page push/preview flow end to end: pushing as draft, previewing it in wp-admin without publishing, then flipping the status header to publish when it's ready to go live.

  • Push updates the title, slug, status and HTML in one call.
  • A draft stays invisible to visitors and search engines.
  • The wp-admin "Preview" row action opens the real rendered page.

Some formatting

Regular text, bold text, italic text, and a link to make sure inline HTML survives the round trip.
