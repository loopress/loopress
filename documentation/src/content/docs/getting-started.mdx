Loopress has two parts: a [WordPress plugin](/wordpress-plugin/) and a CLI, `lps`. The CLI version-controls your site's code and configuration as files in Git, and syncs them with any WordPress environment through the plugin's REST API. The plugin must be active on the site, `lps project config` installs it for you if it's missing.

## Prerequisites

- A WordPress installation (6.0+) with an administrator account
- PHP 8.2+ on the server
- Node.js 22+ on your machine, for the CLI
- A local Chrome, Edge, or Chromium install, only needed for the automatic plugin install below
- For snippets: [WPCode](https://wpcode.com/) or [Code Snippets](https://wordpress.org/plugins/code-snippets/) active on the site

## Quick start (under a minute)

### 1. Install the CLI

```bash
npm install -g @loopress/cli   # or: pnpm add -g @loopress/cli
lps --version
```

The CLI checks npm in the background (at most once a day, never blocking a command) and prints a notice when a newer version exists. Run the same install command to upgrade: the CLI and the WordPress plugin evolve together, so staying current avoids debugging already-fixed issues.

### 2. Connect it to your site

```bash
lps project config
```

Enter your WordPress URL, then choose **Authorize in my browser (recommended)**. This opens your WordPress admin and creates an Application Password for you automatically (WordPress 7.0 or later). If it can't complete, your site runs an older WordPress, or you'd rather enter credentials yourself, the command falls back to manual entry. If you can't find the Application Passwords section in your WordPress admin, see [Application Passwords](/application-passwords/).

If Loopress Full isn't active on the site yet, `project config` offers to install it for you, after a confirmation prompt. When the automatic install can't complete (some managed hosts block uploads), it falls back to instructions for a [manual upload](/wordpress-plugin/#installation). [Concepts](/concepts/#configuring-an-environment) details both steps.

### 3. Initialize your repository

```bash
lps init
```

Run it at the root of your repository. It writes [`loopress.json`](/loopress-json/), which ties the repository to the project you just configured and says where each kind of file lives. See [`lps init`](/cli/init/) for the prompts.

### 4. Sync your first snippets

```bash
# Download your existing snippets as .php files
lps snippet pull

# Edit locally, commit to Git
git add loopress.json .gitattributes snippets/ && git commit -m "chore: import snippets"

# Push changes back to WordPress
lps snippet push
```

This works with either [WPCode](https://wpcode.com/) or the [Code Snippets](https://wordpress.org/plugins/code-snippets/) plugin, whichever is active on the site.
